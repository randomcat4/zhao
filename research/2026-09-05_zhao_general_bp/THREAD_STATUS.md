# 一般素数 `B_p` 线程归档与当前状态

日期：2026-09-05（用户本地时间）

## 冻结问题

令 `p>=5` 为素数，`G=C_p^4`。目标端点是：

> 每个长度 `5p-5` 的 `G` 上序列都含有长度至多 `3p-1` 的非空零和位置子序列。

这就是本目录中的 `B_p`。`p=5` 已在仓库 `research/2026-09-05_zhao_completion/fresh_audit/` 独立闭合；本目录**不重做也不修改**该冻结结论。

## 总裁决

**一般 `B_p` 尚未证明，也没有得到某个 `p>=7` 的严格反例。**

本线程得到的是一系列可全称证明的结构下降。它们显著缩小长原子路线，但最后的两长度分支

```text
所有非空零和长度都属于 {3p, D-1},   D=4p-3
```

仍未排除。因此不能从本目录宣布 `K(C_p^4)=2p` 对所有素数成立。

## Round 1：参数化 `p=5` 的 B 封口

主稿：`round1/Bp_parameterized_review.md`。

主要全称结果：

1. `p=5` 证明中“三个异常第五根”的步骤可替换为任意素数的单位根多重集论证；异常临界值至多两个。
2. 在“所有非空零和纯长 `3p`”的附加假设下，周期以后可直接用三个临界值的容量构造得到禁用的 `p` 项零和；不再需要 `p=5` 的最终二维二次型。
3. 同一条件下，重数至少 `p-3` 的实际值至多两个；达到 `p-2` 的实际值至多一个。
4. 这轮**没有证明纯 `3p` 前提**，也没有处理一般低重数分支。

`round1/verify_bp_candidate.py` 是候选反例的独立位置子集验证器；本线程没有生成反例文件。

## Round 2：实际和值纤维与长原子下降

主稿：`round2/ROUND2_THEOREMS.md`。

主要全称结果：

1. 若存在 `D=4p-3` 原子，则对它的每个外部位置都强制一个长度 `3p+j`、`1<=j<=p-4` 的新原子。因而 `D` 不能是最短非纯原子。
2. 若非纯长度偏移集合为 `J`，`q=|J|`，则 `Z_{3p}` 与所有实际出现的非纯长度计数同余可保持到任意 `p-2-q` 次位置删除。
3. 若 `T` 是最短非纯原子，`|T|=3p+j`，则其外部实际和值纤维多项式次数至多 `d=p-3-j`。
4. 得到线性层 `d=1` 的固定和关系

   `4(1+m_g+m_h+P_{g+h}) ≡ 3m_{g+h} (mod p)`。

5. 平方自由分支中可进一步把最短非纯原子压到 `<=4p-5`。

## Round 3：排除 `Z_D>0` 的只降一级情形

主稿：`round3/ROUND3_THEOREMS.md`。

主要全称结果：

1. 对 `p>=7`：

   `Z_D(S)>0  =>  存在长度 3p+1,...,4p-5 的非纯原子`。

   即 `D` 原子不可能只通过 `D-1` 原子承接下降。
2. 对最短非纯原子次数 `d`，若某值在全序列出现 `n` 次、在原子外出现 `r` 次，则

   `n+r <= p+d-2`。

3. 在仅有 `{3p,D-1}` 两长度的假设下，高阶删除设计给出

   `Z_{3p}(S) >= 8p+1`  （`p>=7`）。

4. 同一两长度分支中，固定 `D-1` 原子 `T`，外部序列 `R` 满足：
   - `R` 的 `2,...,p-1` 项子和全部避开 `supp(S)`；
   - `R` 中两个等和子集必等长；
   - 存在线性泛函 `lambda_T`，对外部实际值 `g` 有 `lambda_T(g)=2 nu_T(g)+1`。

## Round 4：两长度分支的长度分层与秩增长

主稿：`round4/ROUND4_THEOREMS.md`。

固定一个 `D-1` 原子 `T`，外部位置序列 `R=S\T`，`|R|=p-1`。本轮证明：

1. 存在线性长度泛函

   `ell_R : <R> -> F_p`,  且 `ell_R(g)=1` 对每个外部位置值成立。

   等价地，`R` 上任意线性关系都保持系数和。
2. 二阶实际和值纤维给出齐次二次型 `Q_T`；令

   `K_T = Q_T + lambda_T^2`，

   则在 `W=<R>` 上

   `K_T|_W = (ell_R+lambda_T)^2`，

   因而限制型恰为秩一。
3. 任一承载 `D-1` 原子补集的仿射线，都不能对高阶补集设计的交换封闭；存在一次合法二换二，使某个补集的张成维数从 `2` 提升到 `3`。
4. 因而在假想两长度反例中，至少存在一个 `D-1` 原子，其外部补集 `R` 满足

   `dim <R> >= 3`，同时 `K_T` 必退化。

5. 不能额外假设 `K_T` 非退化：局部原子实例确实可出现退化的 `K_T`。这些局部实例不是 `B_p` 反例。

## 当前最窄剩余目标

首先必须关闭：

```text
p>=7，|S|=5p-5，无 <=3p-1 零和，
所有非空零和长度都属于 {3p,4p-4}。
```

现有承重输入包括：

- `Z_{3p} >= 8p+1`；
- `D-1` 补集族的高阶位置删除同余；
- 每个补集都带线性长度泛函 `ell_R`；
- `2,...,p-1` 项外部子和避开 `supp(S)`；
- 等和外部子集必等长；
- 至少一个外部补集秩至少三且对应 `K_T` 退化。

只有排除这一分支后，才能全称宣布“若存在非纯零和，则最短非纯原子长度至多 `4p-5`”，再继续对次数 `d` 下降。
