 Abstract. 
    
 Let  G G  be an additive finite abelian group and let  k ∈ [ exp ⁡ ( G ) , 𝖣 ⁡ ( G ) − 1 ] k\in[\exp(G),\mathsf{D}(G)-1]  be a positive integer.
Denote by  𝗌 ≤ k ​ ( G ) \mathsf{s}_{\leq k}(G)  the smallest positive integer  l ∈ ℕ ∪ { + ∞ } l\in\mathbb{N}\cup\{+\infty\} 
such that each sequence of length  l l  over  G G  has a non-empty zero-sum
subsequence of length at most  k k .
Let  k G ∈ [ exp ⁡ ( G ) , 𝖣 ⁡ ( G ) − 1 ] k_{G}\in[\exp(G),\mathsf{D}(G)-1]  be the smallest positive integer such that  𝗌 ≤ 𝖣 ⁡ ( G ) − d ​ ( G ) ≤ 𝖣 ⁡ ( G ) + d \mathsf{s}_{\leq\mathsf{D}(G)-d}(G)\leq\mathsf{D}(G)+d  for  𝖣 ⁡ ( G ) − d ≥ k G \mathsf{D}(G)-d\geq k_{G} .
We conjecture that  k G = 𝖣 ⁡ ( G ) + 1 2 k_{G}=\frac{\mathsf{D}(G)+1}{2}  for finite abelian groups  G G  with  r ⁡ ( G ) ≥ 2 r(G)\geq 2  and  𝖣 ​ ( G ) = 𝖣 ∗ ​ ( G ) \mathsf{D}(G)=\mathsf{D}^{*}(G) . 
    
 In this paper, we mainly study this conjecture for finite abelian  p p -groups and get some results to support this conjecture. We also prove that  k G ≤ 𝖣 ⁡ ( G ) − 2 k_{G}\leq\mathsf{D}(G)-2  for all finite abelian groups  G G  with  r ⁡ ( G ) ≥ 2 r(G)\geq 2  except  C 2 3 C_{2}^{3}  and  C 2 4 C_{2}^{4} . In addition, we also get some lower bounds for the invariant  𝗌 ≤ k ​ ( G ) \mathsf{s}_{\leq k}(G) . 
  
 
 
 Key words and phrases:  Zero-sum subsequence, Davenport constant, Abelian groups.
 
 
 1.  Introduction 

 
 Let  ℕ \mathbb{N}  denote the set of positive integers, and
 ℕ 0 = ℕ ∪ { 0 } \mathbb{N}_{0}=\mathbb{N}\cup\{0\} . Throughout this paper all abelian
groups will be written additively, and for  n , r ∈ ℕ n,r\in\mathbb{N} , we let
 C n C_{n}  denote the cyclic group of  n n  elements.
Let  G G  be an additive finite abelian group and  G ∗ = G ∖ { 0 } G^{*}=G\setminus\{0\} .
It is well known that  | G | = 1 |G|=1  or  G = C n 1 ⊕ C n 2 ⊕ ⋯ ⊕ C n r G=C_{n_{1}}\oplus C_{n_{2}}\oplus\cdots\oplus C_{n_{r}} , where  1 < n 1 | n 2 ​ | ⋯ | ​ n r 1<n_{1}|n_{2}|\cdots|n_{r} .
Then  r ⁡ ( G ) = r r(G)=r  is the rank of  G G  and
 exp ⁡ ( G ) = n r \exp(G)=n_{r}  is the exponent of  G G . Let 
 

 
 
 S := g 1 ⋯ g l S:=g_{1}\cdots g_{l} 
 
 
 be a sequence with elements in  G G .
We call  S S  a zero-sum sequence if  g 1 + ⋯ + g l = 0 g_{1}+\cdots+g_{l}=0  holds in  G G .
Let  𝖣 ⁡ ( G ) \mathsf{D}(G)  denote the  Davenport constant  of  G G , which is defined
as the smallest positive integer  t t  such that every sequence  S S  over
 G G  of length  | S | ≥ t |S|\geq t  has a nonempty zero-sum subsequence. Set 
 

 
 
 𝖣 ∗ ​ ( G ) := 1 + ∑ i = 1 r ( n i − 1 ) . \mathsf{D}^{*}(G):=1+\sum_{i=1}^{r}(n_{i}-1). 
 
 
 Obviously, we have  𝖣 ⁡ ( G ) ≥ 𝖣 ∗ ​ ( G ) \mathsf{D}(G)\geq\mathsf{D}^{*}(G) .
In most of the cases, a direct zero-sum problem asks for the
the smallest integer  ℓ ∈ ℕ \ell\in\mathbb{N}  such that every sequence  S S  over  G G 
with length  | S | ≥ ℓ |S|\geq\ell  has a zero-sum subsequence with prescribed length. 
 
 
 Let  L ⊂ ℕ L\subset\mathbb{N}  be a nonempty subset and let  𝗌 L ​ ( G ) \mathsf{s}_{L}(G)  be the
smallest  ℓ ∈ ℕ ∪ { ∞ } \ell\in\mathbb{N}\cup\{\infty\}  such that every sequence  S S  over  G G 
has a zero-sum subsequence  T T  with length  | T | ∈ L |T|\in L . Thus for the classical
zero-sum invariants, we clearly have  𝖣 ​ ( G ) = 𝗌 ℕ ​ ( G ) \mathsf{D}(G)=\mathsf{s}_{\mathbb{N}}(G) ,
 η ​ ( G ) = 𝗌 [ 1 , exp ⁡ ( G ) ] ​ ( G ) \eta(G)=\mathsf{s}_{[1,\exp(G)]}(G) ,  𝗌 ​ ( G ) = 𝗌 { exp ⁡ ( G ) } ​ ( G ) \mathsf{s}(G)=\mathsf{s}_{\{\exp(G)\}}(G) , and  𝗌 k ​ exp ⁡ ( G ) ​ ( G ) = 𝗌 { k ​ exp ⁡ ( G ) } ​ ( G ) \mathsf{s}_{k\exp(G)}(G)=\mathsf{s}_{\{k\exp(G)\}}(G) ,
where  𝗌 ⁡ ( G ) \mathsf{s}(G)  is called  Erdös-Ginzburg-Ziv constant  of  G G  and  𝗌 k ​ exp ⁡ ( G ) ​ ( G ) \mathsf{s}_{k\exp(G)}(G)  is called  Generalized Erdös-Ginzburg-Ziv constant  of  G G .
The readers may want to consult one of the surveys or monographs
( [ 16 ,  17 ,  18 ,  19 ,  20 ] ). Moreover,  𝗌 L ​ ( G ) \mathsf{s}_{L}(G)  is also
investigated for various other sets (see, e.g.  [ 3 ,  10 ,  12 ,  14 ,  25 ] ). 
 
 
 In this paper, we investigate the invarient  𝗌 L ​ ( G ) \mathsf{s}_{L}(G)  for  L = [ 1 , k ] L=[1,k] . 
 
 
 Definition 1.1 . 
 
 Denote by  𝗌 ≤ k ​ ( G ) = 𝗌 [ 1 , k ] ​ ( G ) \mathsf{s}_{\leq k}(G)=\mathsf{s}_{[1,k]}(G)  the smallest positive integer  l ∈ ℕ ∪ { + ∞ } l\in\mathbb{N}\cup\{+\infty\} 
such that each sequence of length  l l  has a non-empty zero-sum
subsequence of length at most  k k   ( k ∈ ℕ ) (k\in\mathbb{N}) . 
 
 
 
 The constant  𝗌 ≤ k ​ ( G ) \mathsf{s}_{\leq k}(G)  was introduced by Delorme,
Ordaz and Quiroz  [ 5 ] .
It is trivial to see that  𝗌 ≤ k ​ ( G ) = 𝖣 ​ ( G ) \mathsf{s}_{\leq k}(G)=\mathsf{D}(G)  if  k ≥ 𝖣 ⁡ ( G ) k\geq\mathsf{D}(G) ,
 𝗌 ≤ k ​ ( G ) = η ​ ( G ) \mathsf{s}_{\leq k}(G)=\eta(G)  if  k = exp ⁡ ( G ) k=\exp(G)  and
 𝗌 ≤ k ​ ( G ) = ∞ \mathsf{s}_{\leq k}(G)=\infty  if  1 ≤ k < exp ⁡ ( G ) 1\leq k<\exp(G) . 
 
 
 This invariant has very important research value.
Cohen and Zemor  [ 4 ]  pointed out
a connection between  𝗌 ≤ k ​ ( C 2 r ) \mathsf{s}_{\leq k}(C_{2}^{r})  and coding theory.
Bhowmik and Schlagepuchta  [ 1 ]  used  𝗌 ≤ k ​ ( G ) \mathsf{s}_{\leq k}(G)  to study the Davenport constant  𝖣 ⁡ ( G ) \mathsf{D}(G) .
For more, one can see  [ 2 ,  5 ] .
Freeze and Schmid  [ 8 ]  used  𝗌 ≤ k ​ ( G ) \mathsf{s}_{\leq k}(G)  to study another invariant  𝖣 k ​ ( G ) \mathsf{D}_{k}(G) , which is defined as the smallest integer  ℓ ∈ ℕ \ell\in\mathbb{N}  such that every
sequence  S S  over  G G  of length  | S | ≥ ℓ |S|\geq\ell  has  k k  disjoint nonempty
zero-sum subsequences.
Recently, Gao et al.  [ 13 ]  studied the connection between  𝗌 ≤ k ​ exp ⁡ ( G ) ​ ( G ) \mathsf{s}_{\leq k\exp(G)}(G)  and  𝗌 k ​ exp ⁡ ( G ) ​ ( G ) \mathsf{s}_{k\exp(G)}(G) , i.e., the following conjecture. 
 
 
 Conjecture 1.2 . 
 
 Let  G G  be a finite abelian group. Then 
 

 
 
 𝗌 k ​ exp ⁡ ( G ) ​ ( G ) = 𝗌 ≤ k ​ exp ⁡ ( G ) ​ ( G ) + k ​ exp ⁡ ( G ) − 1 \mathsf{s}_{k\exp(G)}(G)=\mathsf{s}_{\leq k\exp(G)}(G)+k\exp(G)-1 
 
 
 for every  k ∈ ℕ k\in\mathbb{N} . 
 
 
 
 Up to now, the direct and inverse zero-sum problems of  𝗌 ≤ k ​ ( G ) \mathsf{s}_{\leq k}(G)  have been widely studied.
Freeze and Schmid  [ 8 ]  obtained the exact number of  𝗌 ≤ 3 ​ ( C 2 r ) \mathsf{s}_{\leq 3}(C_{2}^{r}) , namely,  1 + 2 r − 1 1+2^{r-1} .
Lindström  [ 28 ]  studied the invariant  𝗌 ≤ 4 ​ ( C 2 r ) \mathsf{s}_{\leq 4}(C_{2}^{r})  when  r r  goes to  + ∞ +\infty .
Wang et al.  [ 33 ]  determined  𝗌 ≤ k ​ ( G ) \mathsf{s}_{\leq k}(G)  for  G = C m ⊕ C n G=C_{m}\oplus C_{n}  with  m | n m|n .
Roy and Thangadurai  [ 29 ]  considered the direct zero-sum problem of  𝗌 ≤ k ​ ( G ) \mathsf{s}_{\leq k}(G)  for a finite abelian  p p -group  G G  with a large exponent by a different method from  [ 33 ] .
Recently, Zhang  [ 34 ]  continued to study this problem for abelian groups of rank three. 
 
 
 For the inverse zero-sum problem of  𝗌 ≤ k ​ ( G ) \mathsf{s}_{\leq k}(G) , the known conclusions are less.
Davydov and Tombakis  [ 6 ]  studied the inverse zero-sum problem of  𝗌 ≤ 3 ​ ( C 2 r ) \mathsf{s}_{\leq 3}(C_{2}^{r})  by the method of coding theory.
Recently, the inverse zero-sum problem of  𝗌 ≤ k ​ ( G ) \mathsf{s}_{\leq k}(G)  with  r ⁡ ( G ) = 2 r(G)=2  has been also solved.
For this, one can see  [ 7 ,  21 ,  22 ,  23 ] .
