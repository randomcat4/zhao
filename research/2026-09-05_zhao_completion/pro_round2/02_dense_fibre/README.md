# PRO-SF2：稠密纤维完整证书

**终点：`DENSE_FIBRE_ELIMINATED_AND_AUDITED`。**

实际证明的结论更强：任意二十一元**集合** `S⊂F_5^4` 都含长度至多十三的非空零和位置子集。这里没有把结论外推成对允许重复的所有二十一位置序列的证明。

完整证明见 `proof_zh.md`。`RED_TEAM.md` 记录边界审核、旧弱命题反例、实现差异和验证等级。完整逐值覆盖由第 9 节的两个闭区间及步长 5 唯一确定；本仓库目录保留核心证明、源码、验证器和执行记录。

## 证明结构

自包含群环论证给出完整删除方程和商群辅助界。另证平方自由二十点引理，提供本题恰好需要的 B 接口；候选 B 旧稿及其大型计算不是依赖。

假想反例必须射影互异，且没有三个不同位置满足 `b+c=2a` 或 `b+c=3a`。精确轮廓不等式迫使某个线性超平面至少含七点。完整三维枚举证明每个超平面最多含九点，并给出大小七至九的全部 1,786 个线性根类。两份不同实现的完整四维搜索排除每个根的全部扩展。

独立扩展校验器在每个节点使用无符号 128 位整数记录不交覆盖账本。总分母和已关闭数均为

```
17972093794219884182340301482
```

这计数的是允许规范化冗余的原始子集，不是互异 `GL(4,5)` 轨道。两份搜索分别访问 34,000,509 和 24,371,246 个节点。它们不逐个循环访问这个巨大原始分母，而由经证明安全的兼容性、正确着色和分枝把它分成全部覆盖的类别。

## 文件说明

`proof_zh.md` 包含所有数学归约、完整整数不等式、规范化证明以及搜索和账本的完备性证明。`integer_branch_schema.json` 指定全部计数、21 点度和低阶删除数据的有限索引，不把必要整数条件当作标签实现的充分条件。

`generate_roots.cpp` 产生固定根表。`verify_roots.py` 使用不同的子集和值和矩阵求逆方法，重新枚举全部有效基归一化对象，并检查完整、不重叠的轨道覆盖。

`farkas_certificate.json` 保存整数系数。`verify_farkas.py` 用按位置的动态规划及任意精度整数检查全部 9,590 个未取商轮廓，不使用优化器或浮点数。

`search_reference.cpp` 是第一份完整扩展搜索。`verify_extensions.cpp` 以不同子集和表示及着色顺序独立重做全部扩展，逐个检查色类正确性，并核对完整原始子集账本。

`audit_interfaces.py` 检查全部 3,125 个删除剩余类及手证的小型整数接口。`unit_search_reference.cpp` 和 `unit_verify_extensions.cpp` 将实现与直接位置子集枚举对照，检查包括长度十三至二十一在内的边界，并穷尽核对几何表。

`negative_controls.py` 拒绝有意破坏的输入。`verify_logs.py` 核对每个根编号、分母、两份初始候选池大小、汇总数及进程退出。单独核对日志不能代替手证和校验器的实际执行。

`execution_report.json` 记录整包重放的实际命令、编译器和解释器、源码与输入哈希、返回码及运行耗时。

## 完整重现

记录环境为 Python 3.13.5、GCC/g++ 14.2.0、Linux x86-64。核心 Python 校验器只用标准库。C++ 程序使用 C++17；独立校验器支持 OpenMP。重放不需要 SAT/ILP 求解器、网络连接、私人账号或专有软件。

在本目录执行：

```bash
python3 -I run_all.py --output replay --threads 4
```

输出目录必须不存在或为空。`run_all.py` 编译五个 C++ 程序，重建根表，运行全部独立 Python/C++ 校验器，运行**两份完整扩展搜索**，再核对新日志。它没有时间、节点、候选池或根前缀限制。`--threads` 只影响独立校验器的并行度，不改变数学覆盖。

编译参数为 `-O3 -std=c++17 -Wall -Wextra -Werror -Wno-misleading-indentation`；独立校验器及其单元测试另加 `-fopenmp`。不要使用 Python `-O`：Python 校验器会拒绝关闭断言的运行方式。

也可单独重跑第二份完整扩展校验器：

```bash
g++ -O3 -std=c++17 -fopenmp -Wall -Wextra -Werror -Wno-misleading-indentation \
    verify_extensions.cpp -o verify_extensions
./verify_extensions rank3_roots.txt 4
```

返回码 2 表示找到候选，该次运行不能认证不存在性。非零错误返回或分母不匹配也不能算排除。交付的完整运行均返回 0。

## 验证边界

本证书是自包含数学归约与可重放完整有限计算，由两份不同的完整扩展实现及分离的有限接口校验器核对。它不是 Lean/Coq 形式化、DRAT 证书或外部第三方签署。哈希只绑定经过核对的文件版本，不证明其中的数学。

大整数须用任意精度整数读取，不得经 JavaScript `Number` 或电子表格浮点数往返。`RESULT.json` 同时以十进制字符串提供完整覆盖分母。
