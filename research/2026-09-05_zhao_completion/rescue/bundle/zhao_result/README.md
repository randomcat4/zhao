# 本轮数学结果与可复核计算

先读 `proof_progress.md`。

**B 的新证明是手工证明，使用原仓库已认证的结构归约。新增有限计算只用于 A 的部分结构排除，不是 B 证明的输入。A 整体尚未闭合。**

文件：

- `proof_progress.md`：全部新推导、原仓库输入边界、A 的有限归约和剩余难点。
- `source/`：实际使用的 C++ 源代码；没有只保存“没找到反例”的随机搜索。
- `logs/`：已完成的有限分母、运行结果及距离判定交叉检查。
- `run_checks.py`：本地复跑入口。

环境为 Python 3.10+ 和 GNU g++（C++17）；不需要网络或额外 Python 包。代码使用 GNU libstdc++ 的 bitset 扫描扩展。

接口与独立七点枚举检查：

```sh
python run_checks.py --suite smoke
```

重跑本文声称完成的全部 A 子类：

```sh
python run_checks.py --suite complete
```

`complete` 也不表示完整 A 已证明，而仅表示本文明确列出的子类。源码按“最大商群类由大到小”的归纳次序运行，不能把某个小 M 搜索独立解释成无条件全类结论。

注意：新增部分尚未经过新的第三方独立终审，也没有宣称完成 Lean 或其他形式化核验。距离表的 12,150,000 次交叉查询是接口检查，不是全部有限树的第二次完整实现。
