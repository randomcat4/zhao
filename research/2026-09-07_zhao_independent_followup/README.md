# Independent follow-up audits, rounds 2-5

This directory archives the independent follow-up audits produced on 2026-09-07 for the general-prime Zhao `A_p` / `B_p` research threads.

The package deliberately distinguishes symbolic theorems, finite/interface models, and negative controls. A `PASS` in a JSON result means only that the listed model/interface checks were reproduced; it is never presented as a proof of a universal endpoint.

## Contents

- `round2/`: nonnegative/integer relaxation models showing that the then-current low-order deletion and fibre conditions were feasible, together with independent verification code and output.
- `round3/`: first nonlinear-realizability audit (Gram/PSD, exchange closure, high-order Möbius), explicit short obstruction certificates, and a `p=7` labelled B-side local model.
- `round4/`: audit of the withdrawn A-side weighted-shadow shortcut. Preserves the valid weighted identities and records the precise invalid implication.
- `round5/`: positive A-side excess-deletion/basis-partition results, a length-layered strengthening for the selected `U`, and the exact missing bridge in three newer B-side reduction claims.

## Current mathematical boundary recorded here

- This package does **not** upgrade the reliable A height bound beyond `h(S) <= p-4`.
- The round-5 A statements on the excess-deletion transform and the existence/basis partition of `U` are positive reusable lemmas.
- The named newer B-side exclusion claims were not present on the readable repository branches at audit time; the package therefore certifies only the reconstructed common comparison/matroid interfaces and explicitly identifies the required clean-completion lemma.
