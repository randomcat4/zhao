## 承重检查

| 接口 | 检查结果 |
|---|---|
| 长度范围 | `N=5p-4 < 2(3p-1)`；无短零和时每个非空零和极小，故只能长 `3p-1,...,4p-3`。 |
| 标量删除方向 | 删 `d` 个位置必须避开一个 `k` 位置零和，因此系数是 `binom(m-k,d)`。 |
| 参数化 | `D=4p-3`，`deg P<=p-2`；`t^D-t^(p-3)` 在 `t=1` 有至少 p 阶零点。`m=N,N-1` 时齐次余项都为零。 |
| 反射删除符号 | `d(p-1)` 是偶数；剩下两个长度项的符号为正、负。第一次被删位置与所需补集值相同时须减去一个副本。 |
| 完备核心 | 核心只需以位置子集表示直线全部元素，不必自身位于直线。余序列长度至少 `D`；较短商群零和块至多 `2p-2`；抵消总代价至多 `3p-3`。 |
| p-2 锚点非零投影 | 精确删去全部 p-2 份 a；系数 1 因无剩余副本排除，0 及 2 至 p-1 因短零和排除。 |
| 短商群和值 | `|U|<=2p` 加至多 `p-2` 个锚点，长度不超过 `3p-2`。唯一未能直接抵消的系数是 1。 |
| 二次矩 | 投影指示多项式次数 `3p-3`，乘 `X^2-1` 后次数 `3p-1`。只能用于严格大于此数的变量数。 |
| 长度加权矩 | 再乘 `ell` 次数为 `3p`。只在 `n>3p` 使用，没有在 `n=3p` 偷用严格次数界。 |
| 端点贡献 | 空集和全集的实际系数都为 0；偶数 n 时二次矩贡献 -2；奇数 n 时长度加权贡献 n。 |
| 余数 | 在 `3p<n<=4p-5` 中不存在 p 的倍数；所以奇数 n 的端点贡献确实非零。 |
| 替换合法性 | T 在删去全部锚点后的 R 内；补回的一份或两份 a 来自 T 外，不复用位置。补集始终非空。 |
| 星图 | 不交边产生实际和值 2a 的四位置商群零和；三角形强迫非零投影标签满足 2q=0。 |
| 最后一次矩 | `3p-2` 为奇数；其实际系数为 -1，因此它与对应二位置块分别贡献 +1。方程是 `2e=0 mod p`。 |
| 星图容量 | 所有叶位置为同一实际值；全局粗高度界给 `1<=e<=p-2`，不是把星图叶子合并成一个位置。 |
| p-3 分支 | 外部二位置和为 2a 时，p-3 个锚点加这个二位置块恰用 p-1 位置覆盖直线。只推出局部排除及 n=3p、3p+1、3p+2 的剩余，不推出该分支全部闭合。 |
| 射影修正 | 等值对修正 p^3；相关非零对修正 p^2；实际等差三元组修正 p^3。不能删除未知非零项。 |
| 低阶重写 | 固定总投影和 t 后是阶乘多项式；未固定 t 时不能无条件声称全局普通多项式次数等于例外数。 |

## 已运行的有限检查

`verify.py` 已实际运行成功；摘要在 `verification_report.json`。程序只用标准库与精确算术。它没有完成一般 p 量词的机器枚举；该量词在高重数分支由正文手证承担。

## 不能从本记录得出的结论

不能宣称 A_p、K(C_p^4)=2p、一般平方自由分支、一般 Farkas 证书、或 p=7 全部重数赋值已闭合。

局部 23 位置例子不满足 A_7 要求的 31 位置长度，不是反例。321 个剩余形式重数型也不是 321 个已经找到的反例。
