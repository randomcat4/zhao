## 2. 长补原子的轴向判据是双向的

对一个与 \(X\) 交于 \(c\) 个位置的 \(F_3\) 块，商补集是

\[
Q_c=q^{\,n_c}W_C,\qquad n_c=p-(c+4),\qquad
\bar\sigma(W_C)=(c+4)q.
\]

任一位置子集唯一写成 \(q^tE\)，其中
\(0\le t\le n_c\)、\(E\subseteq W_C\)。若
\(\bar\sigma(E)=dq\)，则它商零当且仅当 \(t+d=0\pmod p\)。

- \(E=\varnothing\) 时，只有 \(t=0\)，即空集；
- \(E=W_C\) 时，只有 \(t=n_c\)，即整个 \(Q_c\)；
- \(\varnothing\ne E\subsetneq W_C\) 时，存在允许的 \(t\) 当且仅当
  \(d\in\{0,c+4,c+5,\ldots,p-1\}\)。

所以没有非空真商零子集，恰好等价于所有非空真 \(E\) 的轴向和值只
落在 \(q,2q,\ldots,(c+3)q\)。这证明了正文 (8) 的两个方向；它也
覆盖 \(n_c=0\) 的端点，不依赖“只查到长度八”。

脚本的 axial_atom_violations 与此量词一致：动态规划遍历余部的全部
位置子集和，位掩码只去掉大小 \(0\) 与 \(|W_C|\)，再扫描系数
\(0,c+4,\ldots,p-1\)。因此它检查的是每个长补原子的全部内部子集，
不是短块 oracle 的近似。

## 3. 零核心补集的秩二投影分解

零核心时 \(|W_H|\in\{2p,2p+1,2p+2\}>D(C_p^2)=2p-1\)，故
\(\rho(W_H)\) 不是原子，而任一原子分解至少有两个因子。对每个因子
\(E_i\)，以及任意非空真因子子族的并，正文第 2 节的 \(c=0\) 判据
给出

\[
\bar\sigma(E_i)=d_iq,\qquad d_i\in\{1,2,3\},
\]

且每个非空真指标集的系数和模 \(p\) 仍在 \(\{1,2,3\}\)。若因子数
至少三，任意两系数的普通和小于 \(p\)，故必须至多为三；于是不能有
系数三，且至多一个系数二。若因子数至少五，总能选出四个系数一的
因子，违反真子族系数和限制。因此因子数至多四。

全部因子的系数和模 \(p\) 为四；在二、三、四因子情形普通和均小于
\(p\)，所以普通和就是四。逐一分拆只得到

\[
(1,3),(2,2),\qquad(1,1,2),\qquad(1,1,1,1).
\]

因此正文定理 2 的分解数与系数型均成立。它没有分类这些
\(C_p^2\) 原子因子的内部形状，正文对此也没有作更强主张。

## 4. 真实尾迹、交集禁值与 13 型表

设 \(J=H\cap U\) 且 \(\varnothing\ne J\subsetneq U\)。若
\(\bar\sigma(J)=dq\)，则

\[
\bar\sigma(U\setminus J)=-(b+d)q.
\]

因 \(U\setminus J\) 是零核心补原子余部中的非空真子集，完整轴向判据
迫使其和为 \(tq\)、\(t\in\{1,2,3\}\)，从而
\(d=-(b+t)\)。加入 \(b+t\) 个 \(X\)-位置会自动诱导一个商零块。
完整短谱先迫使其长度至多八；长度八只能属于 \(F_3\)，而尾 \(J\ne U\)
又违反正核心尾唯一性。因此长度实际上至多七，即

\[
1\le t\le\min\{3,7-b-|J|\}.
\]

对 13 个 \((p,\ell,b)\) 及 \(j=1,\ldots,\ell-b-1\) 直接代入，恰好
得到正文表 (20)，包括所有空单元格。两个不同零核心块的交集论证也
同样正确：把非空真差集放入另一块的补原子，轴向和值只能为
\(q,2q,3q\)，故交集只能为 \(-q,-2q,-3q\)，并自动诱导正文 (19)
的短块。

这些都是必要约束。非轴向尾迹未被排除，表中非空单元格也没有得到
可实现性证明，所以表 (20) 本身没有删除任何新类型。

## 5. “9 到 \(2p+2\)”与一般 middle gap 的严格区分

脚本确实禁止总长度 \(9\le |K|\le2p+2\) 的商零子集，但这个整段不能
统称为一般 middle gap。正确来源分成两段：

1. proofs/middle_quotient_gap.md 证明的全称空档严格是
   \([p+2,2p+2]\)。若 \(K\) 落在该区间，其补集也落在该区间，
   两侧分别使用 (SQ) 得到系数 \(t,u\in\{1,2,3\}\)，而
   \(t+u\not\equiv0\pmod p\)。
2. \([9,p+1]\) 来自 (SQ) 与已证短块长度窗，而不是 middle gap。
   对该区间内的任一非空商零 \(K\)，有 \(|K|\le p+1\le2p+2\)，
   故 (SQ) 直接给
   \(\sigma(K)=\lambda a\)、\(\lambda\in\{1,2,3\}\)。三族已证长度窗
   分别为 \(F_1:2\text{--}6\)、\(F_2:4\text{--}7\)、
   \(F_3:6\text{--}8\)，所以这样的 \(K\) 长度至多八，与
   \(|K|\ge9\) 矛盾。

故对当前 \(p\ge11\) 分支，两段的并确为 \([9,2p+2]\)，脚本在
quotient_middle_gap_violations 中扫描这整个并集是正确的。这里没有
把 \(p=7\) 时 \([p+2,2p+2]=[9,16]\) 的数字阈值误推广；推广的是
另有证明的两段并集。最新脚本的 docstring 与拒绝消息也已显式注明
“short windows followed by the middle gap”，与这一区分一致。

## 6. --instance 的实际覆盖

逐行检查 validate_instance 后，其实现与正文列出的本地接口相符：

1. 它读取全部 \(2p+8\) 个有位置索引的 \(Y\) 四坐标标签，检查
   \(Y,T,U\) 的商和、实际高度和、实际值重数上界，以及
   \(Y\setminus T\) 中不得再有 \(q\)-标签。\(X\) 的位置没有逐个存入
   JSON，但因其标签完全相同，核心选择数和交数可由二项式系数及交数
   区间无损恢复。
2. has_actual_zero_subsequence 在四维实际标签上对所有 \(Y\) 子集
   做精确子集和动态规划，并遍历 \(0,\ldots,p-4\) 个 \(X\) 位置；只
   跳过空集和整个 \(Z\)。结合先前总和检查，这恰是实际 \(Z\) 原子性。
3. enumerate_short_stars 枚举每个一至八元 \(Y\)-尾及所有可行核心数，
   从同一组商标签和高度标签重建全部长度至多八的商零块，并立即核对
   三族长度窗。零元 \(Y\)-尾无需另列：在 \(p\ge11\)、总长至多八时，
   非空纯 \(X\) 块不可能商零。
4. 全局子集和动态规划直接排除上一节证明的 \([9,2p+2]\) 两段并集；
   它也自动覆盖三个或更多两两不交短块的并，不只实现二块检查。
5. 程序从重建后的星族检查指定 \(T\)、唯一正核心尾 \(U\)，并对每个
   \(F_3\) 星运行完整轴向补原子 oracle；这里没有只检查预选的
   \(T,U\)。
6. star_moments 用
   \((-1)^{L-f}\binom{p-4-k}{c-k}\) 精确计入含固定 \(k\) 个
   \(X\)-位置及固定尾位置的所有实际块。它检查三族零阶、每个 \(Y\)
   位置和一个任意 \(X\) 位置代表、全部位置对类型、全部位置三元组
   类型；由于 \(X\) 全同标号，这一对称压缩没有丢失位置量词。
7. validate_intersections 检查每个 \(F_3\) 块与全部三族块相交、
   \(F_2\) 内部相交、二块 middle-gap 容量，以及所有不同实际
   \(F_3\) 块的交商和非零。对同一尾星的不同 \(X\)-核心，它把可实现
   核心交数的上界减一，从而正确排除“同一实际块与自身比较”。

因此 --instance 在逻辑上确实重建正文承诺的全部自动短块、统一位置
标签、低阶 Hasse/交网络、实际 \(Z\) 原子，以及每个派生 \(F_3\) 补
原子的全部内部子集和。

有两项非数学性的执行边界需要保留：仓库没有提供可传给
--instance 的 JSON 实例，默认运行也不进入该分支，所以本审计没有
声称获得端到端 “PASS exact labelled local instance”；而组合枚举与
子集和状态空间随 \(p\) 急剧增长，对表中大素数它是规范性的精确
validator，不是已展示可行运行时间的求解器。另，默认模式的三组自检
使用 Python assert，不应在 python -O 下作为证书运行；
--instance 的承重拒绝路径使用显式异常，不受此点影响。
