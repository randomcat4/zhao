# 标准原子轴向子集和避障独立验缝

STATUS: CORRECT

审计对象：

- `proofs/standard_atom_axial_subset_avoidance.md`；
- `verify_standard_axial_subset_avoidance.py`。

## 1. 结论

正轴向主命题正确；没有承重缺口。唯一建议显式澄清的是第 102--104 行
的负轴向补集量词：若原子集 \(A\) 的大小为 \(k\) 且
\(\bar\sigma(A)=-t e_i\)，对补集应用正向结论时所需条件是

\[
1\le t\le \min(7,(6-k)+2)=\min(7,8-k),
\]

不能把负轴向结论理解为对所有 \(t\le\min(7,k+2)\) 自动成立。
在此正确范围内，负轴向留下的参数对是

\[
(t,k)\in\{(1,5),(1,4),(1,3),(2,4)\},
\]

即正向四个例外在 \(k\mapsto6-k\) 下的像。此处是局部量词说明，
不影响第 86--99 行的正向禁止表。

## 2. 逐项核对

1. 对每个非空真子集 \(A\subset C\) 和每个由
   \(B_{e_i}\) 中 \(t\) 个不同位置组成的 \(W\)，
   \(E_W=W\mathbin{\dot\cup}(C\setminus A)\) 的商和确为零，长度
   为 \(t+6-k\)。因 \(p-1\ge10>7\)，所有所需 \(W\) 都存在；
   \(E_W\) 非空且是原子的真子集。
2. 在 \(t\le k+2\) 下，长度落在 \(2\) 至 \(8\)。长度窗
   \[
   2,3:\{1\};\quad4,5:\{1,2\};\quad
   6:\{1,2,3\};\quad7:\{2,3\};\quad8:\{3\}
   \]
   与 (SQ) 一致；\(8\le2p+2\) 对 \(p\ge11\) 当然成立。
3. 公共 \((t-1)\)-位置选择论证只需
   \(n-(r+1)\ge t-1\)，即 \(n\ge t+r\)，原文条件精确。
4. 二支撑情形中，重数上界 \(n-3\) 强迫两个值各出现至少三次；
   可实现的换值数形成至少含三个整数的连续区间，且 \(t<p\)，故
   不发生模 \(p\) 回绕碰撞。
5. 三支撑、\(t=3,4\) 的替换和值均有足够位置重数。若原第四值
   与第三值碰撞，再加入的和值只可能与全 \(u\) 和值碰撞；两次
   碰撞给 \(3(v-u)=0\)，被 \(p\ge11\) 排除。
6. \(t=5\) 的困难支确实由重数型 \((4,4,2)\) 及其弱化覆盖。
   写 \(a=v-u,b=w-u\)，五个和值相对 \(5u\) 的偏移为
   \(a,b,2a,a+b,2b\)。其中 \(a+b\) 与其余四个均不同；其余
   只可能发生 \(2a=b\) 与 \(2b=a\) 两种碰撞，而两者同时成立
   给 \(3a=0\)（等价地 \(3(v-w)=0\)）。所以至少有四个和值。
7. 逐项比较长度窗后，未被排除者恰为
   \(\{(1,1),(1,2),(1,3),(2,2)\}\)，没有漏掉中间参数支。

## 3. 计算脚本

脚本的两支撑规范化 \((0,1)\) 覆盖全部两个高度值及允许重数；三
支撑规范化 \((0,1,q)\)、\(q\notin\{0,1\}\) 覆盖全部仿射等价
三支撑。由于 \(t<p\)，仿射规范化保持 \(t\)-子集和值的基数。

实际运行输出：

```text
PASS: exact (t,k) exception table [(1, 1), (1, 2), (1, 3), (2, 2)]
PASS: 668880 normalized support cases for primes 11 <= p <= 53
SCOPE: finite regression; the arbitrary-C avoidance proof is symbolic
```

这只是对 \(11\le p\le53\) 的有限回归；一般 \(p\) 结论由文稿的
符号证明承担，脚本没有被误升级成全称证明。

## 4. 与较弱短轴引理的去重

令 \(D=C\setminus A\)。则

\[
|D|=6-k,\qquad \bar\sigma(D)=-t e_i,\qquad
|W\mathbin{\dot\cup}D|=t+6-k.
\]

所以 **standard_atom_short_axis_subsum.md** 的接口就是本稿构造
\(E_W\) 的补集记号版本。对 \(p\ge11\)，本稿完全包含该旧引理
在长度 \(2\) 至 \(8\) 窗内的排除项；不应把这些重合项重复计作
新结果。

严格新增只发生在长度六：旧引理只处理 \(t=5\)，本稿还排除
\(t=3,4\)，即正向参数 \((t,k)=(3,3),(4,4)\)，或旧稿
\((t,|D|)\) 记号中的 \((3,3),(4,2)\)。长度六的 \(t=1,2\)
仍分别对应未闭合例外 \((1,1),(2,2)\)。此外旧引理保留
\(p\ge7\) 的条件式表述，而本稿的统一精确例外表只声明
\(p\ge11\)；不能反向用本稿覆盖 \(p=7\)。

## 5. 例外的后续收缩

新证明 `proofs/standard_atom_low_axial_height_profiles.md` 严格推出：

- \((1,2),(1,3)\) 中 \(B_{e_i}\) 恰有两个相邻高度纤维；
- \((2,2)\) 中也恰有两个相邻高度纤维，混合纤维对必为二倍块，
  两个同纤维对分别为一倍、三倍块；
- 四个例外中 \(T=C\setminus A\) 都是整个 \(\mathcal F_3\) 的
  横截集，大小依次为 \(5,4,3,4\)。

这些是可立即闭合的新必要条件，但尚未排除四个例外本身。
\((1,2),(1,3)\) 的单高度退化支以及 \((2,2)\) 的单高度、三高度
退化支已经立即关闭；保留下来的完整参数对仍有局部相容高度轮廓。
\((1,1)\) 需要四/五点共度，\((1,2)\) 需要四点共度，
\((1,3)\) 需要三点横截集上的完整三族局部共度系统，\((2,2)\)
需要按两个高度纤维和 \(C\)-交型分类的剩余块变量系统。现有标量
点、对、三点 Hasse 恒等式不足以直接宣布任何一个例外矛盾。
