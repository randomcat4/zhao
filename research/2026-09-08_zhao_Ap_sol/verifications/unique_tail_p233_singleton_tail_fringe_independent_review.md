## 3. \(C_p^2\) 群代数顶层与 \(J_G\) 的归一化

取 \(C_p^2\) 的基并令
\(u=1-X^{e_1},v=1-X^{e_2}\)。在特征 \(p\) 下

\[
\mathbb F_p[C_p^2]\cong
\mathbb F_p[u,v]/(u^p,v^p),\qquad I=(u,v).
\]

所以最高可能总次数为 \(2p-2\)，从而

\[
I^{2p-1}=0,qquad
I^{2p-2}=\mathbb F_pu^{p-1}v^{p-1}
=\mathbb F_pJ_G.
\]

总次数至少 \(2p-3\) 的允许单项式恰为
\(u^{p-1}v^{p-2},u^{p-2}v^{p-1},u^{p-1}v^{p-1}\)，故
\(\dim I^{2p-3}=3\)；\(\dim I^{2p-2}=1\)。脚本的次数计数与此
完全一致。

若 \(S\) 是长度 \(2p-2\) 的零和自由位置序列，则
\(\Psi_S\in I^{2p-2}=\mathbb F_pJ_G\)。其 \(X^0\) 系数为

\[
\sum_{E\subseteq S,\ \sigma(E)=0}(-1)^{|E|}=1,
\]

因为只有空位置子集贡献；而 \(J_G\) 的 \(X^0\) 系数也是一。
因此标量不是未定的非零数，而是精确地

\[
\boxed{\Psi_S=J_G}.
\]

应用于上述两个删点序列，得到
\(\Psi_{C_i}(1-X^{w_j})=\Psi_{C_i}(1-X^{w_k})=J_G\)。

## 4. \(\lambda_i\) 的线性与秩一推论

因为 \(\Psi_{C_i}\in I^{2p-3}\)，对任意 \(w\) 有唯一标量
\(\lambda_i(w)\) 使

\[
\Psi_{C_i}(1-X^w)=\lambda_i(w)J_G.
\]

映射 \(w\mapsto1-X^w\pmod {I^2}\) 是
\(C_p^2\to I/I^2\) 的 \(\mathbb F_p\)-线性映射，且
\(\Psi_{C_i}I^2\subset I^{2p-1}=0\)。故 \(\lambda_i\) 对全部
\(w\) 线性。更显式地，若

\[
\Psi_{C_i}=A u^{p-1}v^{p-2}+B u^{p-2}v^{p-1}
+\gamma J_G
\]

位于顶三维边缘，且 \(w=(a,b)\)，则

\[
1-X^w\equiv au+bv\pmod {I^2},\qquad
\lambda_i(w)=bA+aB.
\]

\(\gamma J_G\) 乘增广理想为零。此推导既没有取消零因子，也没有
把带符号系数解释为非负计数。报告中的 `linearity_checks=10976` 只是
对该公式的有限回归检查；一般线性结论由上述代数推导承担，不依赖
抽样覆盖全部输入。

删点恒等式给
\(\lambda_i(w_j)=\lambda_i(w_k)=1\)。若尾投影秩一，写
\(w_r=c_rv\)，其中 \(v\ne0\)、\(c_r\ne0\)，则
\(c_1+c_2+c_3=0\)。长度七端点 \(H_i\) 强制

\[
c_j\lambda_i(v)=c_k\lambda_i(v)=1,
\]

所以 \(c_j=c_k\)。若有两个长度七端点，两个等式共同迫使
\(c_1=c_2=c_3=c\ne0\)，继而 \(3c=0\)，与 \(p=233\ne3\)
矛盾。注意不同端点可以有不同的 \(\lambda_i\)；证明只在各自端点
内部比较两个值，没有偷用共同泛函。

## 5. 八个长度型与秩二规范形

独立枚举全部
\((c_1,c_2,c_3)\in(\mathbb F_{233}^{\times})^3\)、
\(c_1+c_2+c_3=0\)，总数为
\((p-1)(p-2)=53,592\)。逐个施加每个长度七端点所要求的“其余两
系数相等”，得到：

| 带标号长度型 | 系数三元组数 | 公共伸缩轨道数 |
|---|---:|---:|
| \((7,7,7)\) | 0 | 0 |
| \((7,7,8)\) | 0 | 0 |
| \((7,8,7)\) | 0 | 0 |
| \((7,8,8)\) | 232 | 1 |
| \((8,7,7)\) | 0 | 0 |
| \((8,7,8)\) | 232 | 1 |
| \((8,8,7)\) | 232 | 1 |
| \((8,8,8)\) | 53,592 | 231 |

每个公共伸缩轨道大小为 \(p-1=232\)。单七行的规范系数型确为
\((-2,1,1)\) 的相应排列；无七行的轨道数为
\(53,592/232=p-2=231\)。因此置换意义下秩一只剩
\((7,8,8)\) 与 \((8,8,8)\)。

第一版精确切片把全部端点冻结为长度七，特别包含上述三个单点迹
端点。该三元组已排除秩一；又因每个 \(w_i\ne0\)，不可能秩零，
且环境是二维，故秩恰为二。若 \(w_1,w_2\) 相关，则由
\(w_3=-w_1-w_2\) 三者都会落在同一直线上，矛盾；所以
\((w_1,w_2)\) 是有序基。唯一把该有序基送到 \((e,f)\) 的
\(GL(2,p)\) 变换同时把 \(w_3\) 送到 \(-e-f\)，从而全长七首片
确实只有一个有序 \(GL(2,p)\) 轨道。
