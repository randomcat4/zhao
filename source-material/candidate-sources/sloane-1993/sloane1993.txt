2. Intersecting codes
     A linear code C of length N , dimension K and minimal Hamming distance D, i.e. an

                                            ABSTRACT

     A t-covering array is a set of k binary vectors of length n with the property that, in any t
coordinate positions, all 2 possibilities occur at least once. Such arrays are used for example
                             t




in circuit testing, and one wishes to minimize k for given values of n and t. The case t = 2 was
